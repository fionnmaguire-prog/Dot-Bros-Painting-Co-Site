# Web Assets

This folder stores optimized assets that are safe to reference directly from the website code.

Only production-ready web assets should live here.

What belongs here:
- Compressed images prepared for the live site
- Final SVG assets used by the frontend
- Web-optimized textures, icons, logos, and decorative graphics
- Organized section-specific assets for the hero, intro, services, and portfolio

What does not belong here:
- Editable PSD, AI, or Blender source files
- Temporary exports that still need cleanup or optimization
- Oversized working assets that are not ready for browser delivery

Everything referenced by `index.html`, `src/main.js`, or `src/style.css` should come from this asset tree.

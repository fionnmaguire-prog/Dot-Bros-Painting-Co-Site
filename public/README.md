# Public Files

This folder holds static files that can be served directly by the Vite app.

What belongs here:
- Final public-facing assets needed by the website
- Files inside `public/assets/` that are optimized for frontend use
- Favicons, static icons, and other direct public files used by the app

What does not belong here:
- Editable source design files
- Temporary exports that still need optimization
- Large working files from Photoshop, Illustrator, or Blender

Use `public/assets/` for organized website imagery, logos, textures, intro assets, icons, and other optimized production files.
